# Прогнозирование банкротства компаний

Проект, выполненный во время стажировки в **НИФИ**.

## Задача
На основе бухгалтерской и финансовой отчётности российских компаний (~600 млн строк) построить модель, оценивающую риск банкротства.

## Подход
- **SQL**: извлечение и агрегирование данных, оптимизация тяжёлых запросов через CTE, оконные функции, индексы и работу с партиционированными таблицами; диагностика через `EXPLAIN ANALYZE`.
- **Предобработка (Python, pandas, numpy)**: очистка, обработка пропусков и выбросов, расчёт финансовых коэффициентов (ликвидность, рентабельность, оборачиваемость, долговая нагрузка).
- **Feature engineering**: формирование индикаторов риска и временных производных коэффициентов.
- **ML-модели (scikit-learn)**: логистическая регрессия, деревья решений, бустинги.
- **Оценка качества**: ROC-AUC, precision/recall, F1, confusion matrix.

## Стек
Python (pandas, numpy, scikit-learn, matplotlib), SQL, Git.

## Результат
- Построена сравнительная таблица моделей по ключевым метрикам.
- Выявлены наиболее предиктивные финансовые коэффициенты.
- Подготовлены витрины данных и аналитические отчёты для мониторинга риска.
