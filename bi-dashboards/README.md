# BI Dashboards

Дашборды для сквозной аналитики компании (операционная, HR и финансовая), разработанные в **Альфастат**.

## Что сделано
- Согласовал с бизнесом структуру метрик и KPI ключевых подразделений.
- Спроектировал модель данных (звезда / снежинка) и слой агрегации под BI.
- Реализовал интерактивные дашборды с фильтрами и навигацией по разрезам бизнеса.
- Настроил DAX-меры в Power BI: расчёт долей, динамики, сравнений периодов.
- Внедрил автоматические проверки качества данных перед публикацией витрин.

## Инструменты
- **Power BI** — основной инструмент для финансовой аналитики, DAX-меры.
- **Yandex DataLens** — оперативные дашборды.
- **Apache Superset** — отчёты на ClickHouse-витринах.

## Темы дашбордов
- Операционные показатели и нагрузка ресурсов.
- HR-аналитика: численность, текучесть персонала, прогноз увольнений.
- Финансы: выручка, маржинальность, прогноз и план-факт.
