# BI Dashboards

Сквозная аналитика и продуктовые дашборды (операционка, HR, финансы, маркетинг).

## Стек
- **Apache Superset** — основной BI-слой поверх ClickHouse и PostgreSQL.
- **Yandex DataLens** — оперативные дашборды и быстрые ad-hoc отчёты.
- **Power BI** — финансовая аналитика и DAX-меры.
- **ClickHouse / PostgreSQL** — витрины и agg-таблицы.

## Что делал
- Согласовывал с бизнесом структуру метрик и KPI ключевых подразделений.
- Проектировал модель данных (звезда / снежинка) и слой агрегаций под BI.
- Реализовывал интерактивные дашборды с фильтрами (дата, статус, отделение, этап) и навигацией по табам.
- Настраивал row-level security и роли доступа.
- Внедрял автоматические проверки качества данных перед публикацией витрин.
- Писал DAX-меры в Power BI: расчёт долей, динамики, сравнений периодов, скользящих средних.

## Типы реализованных дашбордов

### HR / рекрутмент
- Воронка вакансий по этапам (скрининг → интервью → оффер → найм).
- Время жизни вакансии: среднее, медиана, перцентили, гистограмма по бакетам.
- Срез по статусам, типам, отделениям.
- Анализ нагрузки и SLA рекрутёров.
- Прогноз по плану найма vs факт.

### Операционные KPI
- Дашборд по плану/факту выручки и маржинальности.
- Сегментация клиентов и продуктов (ABC/XYZ).
- Динамика загрузки ресурсов с drill-down по подразделениям.

### Маркетинг
- Конверсии по каналам и кампаниям.
- LTV / CAC / Payback по когортам.
- Атрибуция и сравнение источников трафика.
