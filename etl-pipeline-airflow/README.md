# ETL Pipeline на Airflow

Кейс из работы в **Альфастат** (BI-аналитик).

## Задача
Объединить разрозненные источники данных (выгрузки из учётных систем, БД, внешние файлы) в единое аналитическое хранилище для сквозной операционной, HR и финансовой аналитики.

## Подход
- Спроектировал DAG'и в Apache Airflow для регулярной загрузки и трансформации данных.
- Разделил пайплайн на слои: raw → staging → cleansed → marts.
- Реализовал идемпотентные таски с возможностью бэкфилла.
- Внедрил автоматические проверки качества данных (Data Quality checks) на ключевых этапах.

## Стек
Apache Airflow, PostgreSQL, ClickHouse, Python (pandas), SQL.

## Результат
- Сквозная аналитика покрыта стабильным ежедневным пайплайном.
- Бизнес получает актуальные данные на дашбордах без ручных выгрузок.
