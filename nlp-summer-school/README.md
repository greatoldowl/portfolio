# NLP — Летняя школа

Проект в рамках **мастерской анализа текстовых данных** (Летняя школа, 2025).

## О чём
Прикладные задачи обработки естественного языка: предобработка текстов, векторизация, классификация и тематическое моделирование.

## Стек
Python, pandas, numpy, scikit-learn, NLP-библиотеки (NLTK / spaCy / transformers — в зависимости от задачи).

## Что отработал
- Очистка и нормализация текстов (токенизация, лемматизация, удаление стоп-слов).
- Векторизация: bag-of-words, TF-IDF, эмбеддинги.
- Классические ML-классификаторы для текстов.
- Базовая работа с предобученными моделями для семантических задач.
