# Миграция хранилища PostgreSQL → ClickHouse

Кейс из работы в **Альфастат**.

## Задача
Часть аналитической нагрузки упёрлась в возможности PostgreSQL: материализованные представления долго пересчитывались, а дашборды медленно отрисовывались. Нужно было перевести аналитический контур на OLAP-движок.

## Что сделал
- Спроектировал целевую модель данных в ClickHouse: подбор движков таблиц (`MergeTree`, `ReplacingMergeTree`, `AggregatingMergeTree`), ключей сортировки и партиционирования.
- Перевёл расчёты на материализованные представления ClickHouse.
- Перенёс ETL-загрузку и согласовал её с Airflow.
- Адаптировал SQL-запросы и BI-модели под OLAP-подход.

## Стек
ClickHouse, PostgreSQL, SQL, Apache Airflow, Power BI / DataLens / Superset.

## Результат
- Ускорение обновления материализованных представлений в **~4 раза**.
- Заметное снижение времени отрисовки дашбордов.
- Возможность работать с большими объёмами данных без деградации.
