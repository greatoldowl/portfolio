# SQL Optimization Cases

Подборка подходов к оптимизации SQL-запросов из реальных задач (Альфастат, НИФИ).

## Что обычно делаю
- Переписываю громоздкие подзапросы на **CTE** и **оконные функции**.
- Привожу запросы к корректным JOIN'ам, убираю скрытые декартовы произведения.
- Подбираю **индексы** (B-tree, частичные, составные) под профиль нагрузки.
- Использую **партиционирование** больших таблиц по дате/категории.
- Читаю и сравниваю планы через `EXPLAIN (ANALYZE, BUFFERS)` в PostgreSQL.

## ClickHouse-специфика
- Подбор движка таблиц: `MergeTree`, `ReplacingMergeTree`, `AggregatingMergeTree`.
- Ключи сортировки и партиционирования, материализованные представления.
- Перевод PostgreSQL-логики в OLAP-стиль (предагрегаты вместо подзапросов).

## Типичные результаты
- Снижение времени тяжёлых аналитических запросов в разы.
- Ускорение обновления материализованных представлений (~4x при миграции на ClickHouse).
- Стабильное время отрисовки дашбордов на больших датасетах.
